Setup Instructions

Claude Code

Claude Code is the AI vibe coder we use in class. You talk to it in plain English, and it writes the code, runs commands, and builds your projects for you. We use it in the Claude desktop app.

Install the Claude desktop app

  • Go to https://claude.ai/download
  • Download the app for Windows or Mac
  • Run the installer and accept the default options
  • On a Mac, drag Claude into your Applications folder, then open it from there

Log in with your account

  • Open the Claude app and click Log in
  • Sign in with the Claude account you will use for class. If you don't have one yet, create one at claude.ai
  • Claude Code needs a paid Claude plan (Pro or higher). If the class gives you an account, use that one

Open Claude Code

  • In the Claude app, click the Code tab
  • Choose your class folder as the folder to work in. Claude Code can only see and change files in the folder you pick
  • Type a message to test it, like "Say hi and tell me which folder you are working in."

Claude Code asks for permission before it runs commands or changes files. Read what it wants to do, then click allow.

Node.js

For a video walkthrough on how to install Node.js, see this YouTube tutorial.

Install Node.js

  • Go to https://nodejs.org/
  • Download the LTS version for your operating system (recommended)
  • Run the installer and follow the prompts
  • Note: The installer may offer optional tools for building native modules. If you run into errors during this step, you can safely skip those optional tools.

Check that Node and npm work

Open Claude Code and ask: "Check if I have Node and npm installed and tell me the versions." If it reports version numbers, Node.js is installed.

Or check without AI: Open a terminal (PowerShell on Windows, Terminal on Mac) and run:

node -v
npm -v

If you see version numbers, Node.js is installed.

Create a React app

You don't need to install React separately. Node.js comes with npx, which downloads React for you when you make an app. Create a folder for your app (e.g. my-app), open a terminal in that folder, and run:

npx create-react-app .

That scaffolds the React files in the current folder. To run the app:

npm start

The app opens in your browser at http://localhost:3000. Or just ask Claude Code: "Make a React app in this folder and run it."

Python

Install Python

  • Windows:
    • Go to python.org/downloads/windows
    • Download and run the latest installer
    • Important: Check the box that says Add Python to PATH before clicking "Install Now"
  • Mac:
    • Go to python.org/downloads/mac-osx
    • Download the latest macOS .pkg installer
    • Open the installer and follow the installation steps

Check that Python works

Open Claude Code and ask: "Check if I have Python installed and tell me the version." If it reports a version number, you are set.

Or check without AI: Open a terminal and run:

python --version

On a Mac, use python3 --version. If you see a version number, Python is installed.

GitHub

Video walkthroughs for installing Git: Windows · Mac.

Create a GitHub Account

  • Go to https://github.com/
  • Click Sign up and follow the instructions to create a free account.
  • Verify your email address.

Download and Install Git

  • Windows: Go to https://git-scm.com/download/win and download the "64-bit Git for Windows Setup." Run the installer and accept the default settings.
  • Mac: Open Terminal and type git. A popup will ask if you want to install the "Command Line Developer Tools." Click Install. (Or use brew install git if you have Homebrew.)

Check that Git works

Open Claude Code and ask: "Check if I have Git installed and tell me the version." If it reports a version number, Git is installed.

Or check without AI: Open a terminal and run:

git --version

If you see a version number, Git is installed. If you get an error, finish the install step above and try again.

Connect Claude Code to GitHub

Once Git is installed, open Claude Code and ask:

"Help me connect to GitHub. Set my global git user.name to Your Name and user.email to your@yale.edu, then walk me through signing in to GitHub."

Use the same email as your GitHub account. Claude Code will run the Git commands for you. When it tells you to sign in, complete the browser prompt once. It cannot do that part for you.

After that, tell Claude Code what you want in plain English when you need to clone, commit, or push.

Vibe Coding

This is how we run vibe coding in class (and how you should start each homework or lecture project). Use Claude Code. Work one folder at a time.

  1. Open your class folder in Claude Code (pick it as the working folder in the Code tab). It should contain folders like Lecture 1, Lecture 2, … and Homework 1, Homework 2, and so on.
  2. Tell the AI which folder you're using today. Example: "Today we are working in Lecture 3. Put all my stuff there."
  3. Make it prove it's in the right folder. Ask it to write a short joke there, then check that joke.txt appears inside that lecture or homework folder.
  4. Tell the AI to set up the software environment in that folder. For Python, ask it to create a virtual environment (venv). For React, ask it to scaffold a React app there.
  5. Tell the AI to install the packages you need. For Python, that usually means a requirements.txt and pip install -r requirements.txt. For React, that usually means package.json and npm install.
  6. Point the AI at your API keys. Example: "My API keys are in the .env file in the root of my class folder." Do not paste keys into chat.
  7. Start vibe coding the lecture or homework project for that session.
